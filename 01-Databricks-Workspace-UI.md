# Chapter 1: Databricks Workspace UI

## Introduction

This chapter introduces the Databricks Workspace UI and the main ways to navigate it.

## Home Page Walkthrough

Open the home page either by selecting **Databricks** in the upper-left corner or by choosing **Home** in the left navigation pane.

### Your resources

The **Your resources** area provides shortcuts to workspace items:

- **Suggested** — Assets you have used recently.
- **Favorites** — Items you have starred across the platform.
- **Popular** — Assets with high engagement from you or other workspace users.
- **Mosaic AI** — AI models and features available to explore in a full Databricks workspace.
- **What’s New** — Updates about features, releases, and related announcements in a full workspace.

Free Edition includes Suggested, Favorites, and Popular. Mosaic AI and What’s New are available in the full version.

## Navigation Sidebar

The sidebar is on the left and contains common entry points to Databricks features. To make more room, select the icon in the upper-left to collapse it. When collapsed, hover over the left edge to display the navigation; select the icon again to expand it.

### New

Use **+ New** to create items such as notebooks, queries, dashboards, Genie spaces, and jobs. The menu also lets you add or upload data.

### Compute

Compute in Free Edition is serverless and managed for you. The **Compute** menu lets you view SQL warehouses, Vector Search endpoints, and Apps. Free Edition limits which compute objects you can create.

### Workspace

Choose **Workspace** to open the browser for viewing, editing, sharing, and creating objects such as notebooks, queries, and dashboards. Usually, the person who creates an object owns it and is the only user or principal who can grant others access.

### Catalog

**Catalog** opens Catalog Explorer and Unity Catalog, where you can browse data assets such as volumes, models, functions, and tables. Assets use a three-part namespace: catalog, schema, and data object. Catalog Explorer also shows permissions, history, and lineage.

## Navigation Sidebar Sections

The sidebar groups tools into three main sections: **SQL**, **Data Engineering**, and **AI/ML**. These sections help you find tools for different kinds of work. Databricks Agents are not available in Free Edition.

## Conclusion

In this lesson you learned how to:

- Navigate the Lakehouse workspace home page.
- Find the UI areas for Compute, Workspace, and Catalog.
- Access your workspace objects and data assets in Unity Catalog.
